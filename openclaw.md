# Причини використовувати OpenClaw та переваги над аналогами

- **Повна приватність**: Завдяки підтримці локальних моделей (наприклад, через Ollama), ваші дані не залишають ваш комп'ютер. Це критично для роботи з конфіденційною інформацією.
- **Автономність та дії**: На відміну від звичайних чат-ботів, OpenClaw може виконувати дії: керувати файлами, запускати команди в терміналі, переглядати веб-сторінки та керувати поштою.
- **Інтеграція з месенджерами**: Можливість керувати своїм комп'ютером та ШІ-асистентом безпосередньо з Telegram, WhatsApp або Discord.
- **Розширюваність (Skills)**: Ви можете створювати власні "навички" для асистента або використовувати готові від спільноти.
- **Відкритий код**: Система прозора, безкоштовна та постійно вдосконалюється спільнотою.
- **Економія ресурсів**: Використання локальних моделей дозволяє не платити за підписки на хмарні сервіси (ChatGPT Plus, Claude Pro), використовуючи потужність власного заліза.

# Гайд по встановленню OpenClaw з локальною Gemma4:e4b

## 1. Встановлення Ollama

**Windows:**

`irm https://ollama.com/install.ps1 | iex`

**macOS & Linux:**

`curl -fsSL https://ollama.com/install.sh | sh`

## 2. Завантаження моделі

`ollama pull gemma4:e4b`

## 3. Встановлення OpenClaw

**Windows:**

`powershell -c "irm https://openclaw.ai/install.ps1 | iex"`

**macOS & Linux:**

`curl -fsSL https://openclaw.ai/install.sh | bash`

## 4. Налаштування OpenClaw

`openclaw onboard`

## 5. Під'єднання до телеграм чат боту

1.  **Створіть бота**: Знайдіть `@BotFather` у Telegram та створіть нового бота командою `/newbot`.
2.  **Отримайте токен**: Скопіюйте API Token, який надасть BotFather.
3.  **Налаштуйте OpenClaw**: Запустіть у терміналі `openclaw onboard`.
4.  **Виберіть Telegram**: Коли програма запитає про канали зв'язку, оберіть Telegram та вставте ваш токен.
5.  **Налаштування безпеки**:

Отримайте свій Telegram User ID: Для цього скористайтеся Telegram-ботом, наприклад, @userinfobot (він видасть ваш унікальний числовий ідентифікатор).

`openclaw config set security.groupPolicy "allowlist"`

`openclaw config set security.allowlist "123456789"` (замініть 123456789 на свій User ID)

6.  **Запустіть асистента**: Тепер ви можете писати своєму боту в Telegram!

# Корисні команди

## Ollama:

- `ollama run <назва_моделі>` — запустити модель у терміналі.
- `ollama stop <назва_моделі>` — зупинити модель.
- `ollama pull <назва_моделі>` — завантажити або оновити модель.
- `ollama list` — переглянути список завантажених моделей.
- `ollama ps` — переглянути список запущених моделей.
- `ollama rm <назва_моделі>` — видалити модель.
- `ollama serve` — запустити сервер Ollama вручну (якщо не запущений як сервіс).

## OpenClaw:

- `openclaw onboard` — початкове налаштування (моделі, месенджери, доступи).
- `openclaw update` — оновлення до останньої версії.
- `openclaw gateway start` — запуск асистента.
- `openclaw gateway stop` — зупинка роботи.
- `openclaw gateway restart` - перезапускає шлюз для застосування змін у конфігурації

- `openclaw dashboard` - відкриває графічну вебпанель OpenClaw у вашому браузері
- `openclaw logs --follow` - відстежує активні фонові логи в реальному часі для пошуку несправностей
- `openclaw doctor` - автоматично запускає перевірку стану системи та виправляє поширені проблеми з конфігурацією
- `openclaw status --all` - відображає детальний діагностичний огляд активних сесій та підключених каналів
